# DevsTeach #009 : ta première page web

> Source : channels/scripts-complets.md. Les lignes « > » ne sont pas lues.
> Écran : fichier `index.html` créé. Le point d'exclamation qui se transforme en squelette :
> ```html
> <!DOCTYPE html>
> <html lang="fr">
> <head>
>   <meta charset="UTF-8">
>   <meta name="viewport" content="width=device-width, initial-scale=1.0">
>   <title>Mon site</title>
> </head>
> <body>
>   <h1>Bonjour !</h1>
> </body>
> </html>
> ```
> Étiquettes « head = carte d'identité », « body = ce qu'on voit ». Balises ouvrante et fermante surlignées comme des parenthèses. Navigateur qui affiche « Bonjour ! ». Teaser.

[solennel, amusé] Mesdames et messieurs, voici le moment que tu attendais : ta première page web.
Dans VS Code, crée un fichier index point html. Index, c'est le nom de la page d'accueil : celle qui s'ouvre en premier.
Maintenant, astuce : tape un point d'exclamation, puis appuie sur Entrée. VS Code écrit le squelette de la page tout seul.
Le HTML fonctionne avec des balises : une balise qui ouvre, une balise qui ferme, comme des parenthèses. La partie head, c'est la carte d'identité de la page. La partie body, c'est tout ce qu'on voit.
Dans le body, écris : chevron, h un, chevron, Bonjour, puis la balise fermante.
[énergique] Ta mission : enregistre, puis double-clique sur index point html dans ton dossier. Ton navigateur l'ouvre. Tu viens de créer une page web.
Et prends l'habitude : add, commit, push.
