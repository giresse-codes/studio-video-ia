# DevsTeach #008 : ton premier envoi sur GitHub

> Source : channels/scripts-complets.md. Les lignes « > » ne sont pas lues.
> Écran : fichier README.md créé dans VS Code. Commandes à l'écran, une par une :
> ```text
> git config --global user.name "Ton Nom"
> git config --global user.email "ton@email.com"
> git init
> git add .
> git commit -m "Premier commit"
> git branch -M main
> git remote add origin https://github.com/TON-PSEUDO/mon-site.git
> git push -u origin main
> ```
> Gag des cartons : mettre dans le carton, fermer et écrire, envoyer par la poste. Page GitHub qui s'actualise et affiche le README. Teaser « Ta première page web ».
> Légende de publication :
>   Épisode 8 : add, commit, push. Ton premier code part sur GitHub. Toutes les commandes sont à l'écran.
>   Ton README est en ligne ? Montre-moi.
>   #apprendreacoder #github #git #tutoriel #devsteach

[énergique] Aujourd'hui, ton code part sur internet.
D'abord, crée un fichier README point md dans ton dossier « mon-site », et écris une phrase dedans, par exemple : mon premier site.
La première fois, dis à Git qui tu es : ton nom et ton e-mail, avec deux commandes git config. Elles sont à l'écran.
Ensuite, retiens trois mots. Add : tu choisis ce que tu veux sauvegarder. Commit : tu crées le point de sauvegarde, avec un message. Push : tu l'envoies sur GitHub.
[amusé] Add, c'est mettre dans le carton. Commit, c'est fermer le carton et écrire dessus. Push, c'est l'envoyer par la poste.
Pour la toute première fois, GitHub t'a donné les commandes exactes sur la page de ton dépôt : copie-les dans ton terminal. Une fenêtre peut te demander de te connecter à GitHub.
[énergique] Ta mission : actualise la page de ton dépôt. Si ton README apparaît, c'est gagné.
