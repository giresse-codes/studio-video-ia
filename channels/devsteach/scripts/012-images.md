# DevsTeach #012 : les images

> Source : channels/scripts-complets.md. Les lignes « > » ne sont pas lues.
> Écran : page grise et triste qui se colore quand l'image arrive. Code :
> ```html
> <img src="images/photo.jpg" alt="Moi devant mon ordinateur, en train de coder">
> ```
> Étiquettes « src = où est le fichier », « alt = description ». Lecteur d'écran qui lit « image » d'une voix robotique (gag), puis la vraie description. Arborescence : `mon-site/index.html`, `mon-site/images/photo.jpg`. Écran « TA MISSION ». Teaser.
> Légende de publication :
>   Épisode 12 : ajoute une image avec la balise img, et n'oublie jamais l'attribut alt. Voici pourquoi.
>   Tu as mis quelle image ?
>   #apprendreacoder #html #accessibilite #devweb #devsteach

[curieux] Une page sans image, c'est triste. On en ajoute une.
La balise image, c'est img. Elle est spéciale : elle ne se ferme pas, parce qu'elle n'a pas de contenu entre deux balises.
Elle a besoin de deux attributs. src, la source : le chemin vers ton fichier image. Et alt, le texte alternatif : une description de l'image.
[sérieux] Alt, c'est l'attribut que tout le monde oublie. Il est lu à voix haute aux personnes aveugles, et il s'affiche si l'image ne charge pas.
[amusé] Sans alt, pour un lecteur d'écran, ta belle photo, c'est juste : image. Merci, très utile.
Range tes images dans un dossier images, à côté de tes pages.
[énergique] Ta mission : crée un dossier images, mets-y une photo, et ajoute-la dans index point html avec une vraie description dans alt. Puis add, commit, push.
