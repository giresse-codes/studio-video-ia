# DevsTeach #001 : ouvrir un site

> Style : « Schéma » + « Écran code » pour le code. Avatar en tenue bleue.
> Ancres (événement visuel lié à un mot) :
> @seconde → chronomètre « 1 s », site qui s'ouvre
> @pizza → téléphone qui commande une pizza
> @navigateur → fenêtre de navigateur avec un gros chiffre 1
> @DNS → annuaire géant qui répond avec une adresse en chiffres, gros chiffre 2
> @serveur → ordinateur-pizzeria « ouvert 24h/24 », gros chiffre 3
> @HTML → squelette ; @CSS → vêtements ; @JavaScript → muscles, gros chiffre 4
> @page → la page s'assemble comme une pizza qui arrive
> @mission → écran « TA MISSION » : clic droit → Inspecter, puis view-source: sur téléphone, titre surligné dans le code
> @URL → teaser « Prochain épisode : l'URL »

[étonné] Tu ouvres un site en une seconde. Mais pendant cette seconde, il se passe quatre étapes.
Imagine que tu commandes une pizza.
Étape un : tu tapes l'adresse du site. Ton navigateur, c'est toi qui commandes.
Étape deux : il demande à un annuaire, le DNS, où se trouve le site. L'annuaire répond avec une adresse en chiffres.
Étape trois : la commande part vers le serveur, un ordinateur toujours allumé. [amusé] C'est la pizzeria : elle ne dort jamais.
Étape quatre : le serveur renvoie des fichiers. Le HTML pour la structure, le CSS pour le style, le JavaScript pour les actions. Ton navigateur assemble tout, et la pizza arrive : ta page.
[énergique] Ta mission : sur ordinateur, fais un clic droit sur un site, puis « Inspecter ». Sur téléphone, écris view-source: devant l'adresse. Trouve le titre de la page dans le code.
Tu l'as trouvé ? Dis-moi quel site en commentaire. Prochain épisode : l'URL.
