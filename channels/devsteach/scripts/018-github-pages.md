[solennel] Depuis quatorze épisodes, ton site vit sur ton ordinateur. Aujourd'hui, il part dans le monde.
GitHub a un service gratuit, GitHub Pages, qui transforme ton dépôt en site web.
Une condition : ta page d'accueil doit s'appeler index point html, et être à la racine du dépôt. Tu l'as déjà fait.
[énergique] Ta mission, en quatre clics. Sur la page de ton dépôt, va dans Settings, puis Pages. Dans Source, choisis Deploy from a branch. Choisis la branche main, le dossier racine, et clique sur Save.
Attends une ou deux minutes. GitHub t'affiche ton adresse : ton pseudo, point github point io, slash mon-site.
[ému, amusé] Envoie-la à ta mère. Elle ne comprendra pas, mais elle sera fière.
À chaque push, ton site se met à jour tout seul.
[souriant] Prochain épisode : ton site sur téléphone. Mets l'adresse de ton site en commentaire, je veux le voir.
