[direct] Pour cuisiner, il te faut une cuisine. Pour coder, il te faut un éditeur de code.
Tu pourrais écrire du code dans le bloc-notes. [amusé] Mais c'est comme cuisiner avec une petite cuillère.
Un éditeur de code, c'est une cuisine équipée : il colore ton code pour que tu le lises mieux, il te propose la suite quand tu tapes, et il te signale certaines erreurs.
Le plus utilisé s'appelle Visual Studio Code, VS Code pour les intimes. Il est gratuit, et il marche sur Windows, Mac et Linux.
[énergique] Ta mission : va sur code point visualstudio point com, télécharge VS Code et installe-le. Ensuite, crée un dossier « mon-site » sur ton ordinateur, et ouvre-le dans VS Code, avec Fichier, puis Ouvrir le dossier.
C'est dans ce dossier qu'on va construire ton premier site.
[souriant] Prochain épisode : le terminal, la fenêtre noire qui fait peur. Tu l'as installé ?
