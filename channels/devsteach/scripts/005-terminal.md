Le terminal, c'est une façon de parler à ton ordinateur par écrit, au lieu de cliquer. Tu tapes une commande, il l'exécute.
Dans VS Code, ouvre-le avec le menu Terminal, puis Nouveau terminal.
Trois commandes pour commencer. P W D : il te dit dans quel dossier tu es. L S : il liste ce qu'il y a dans le dossier. C D, suivi d'un nom : tu entres dans un dossier. Et C D point point : tu remontes d'un cran.
Ces commandes marchent sur Mac, sur Linux, et dans le terminal de VS Code sous Windows.
[énergique] Ta mission : ouvre le terminal dans ton dossier « mon-site », tape P W D, puis M K D I R test, puis L S. Tu viens de créer un dossier sans cliquer.
