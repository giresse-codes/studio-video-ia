[curieux] Tu as déjà perdu une partie de jeu vidéo parce que tu n'avais pas sauvegardé ?
En code, c'est pareil. Tu modifies quelque chose, tout casse, et tu ne sais plus comment c'était avant.
Git, c'est un système de points de sauvegarde pour ton code. Chaque point s'appelle un commit. [amusé] Tu fais une bêtise ? Tu reviens au dernier point de sauvegarde, comme dans un jeu.
Et Git garde l'historique complet : qui a changé quoi, et quand. C'est pour ça que presque tous les développeurs du monde l'utilisent.
[énergique] Ta mission : va sur git tiret scm point com, télécharge Git et installe-le. Puis, dans le terminal de VS Code, tape : git, espace, tiret tiret version. Si un numéro de version s'affiche, Git est installé.
[souriant] Prochain épisode : GitHub. Git et GitHub, ce n'est pas la même chose. Tu as un numéro de version ?
