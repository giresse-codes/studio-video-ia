>   #apprendreacoder #github #git #devweb #devsteach

[direct] Git et GitHub, ce n'est pas la même chose. [amusé] Et oui, les noms sont mal choisis.
Git, c'est l'appareil photo : il prend les points de sauvegarde, sur ton ordinateur.
GitHub, c'est l'album en ligne : un site où tu envoies ces sauvegardes, pour ne rien perdre si ton ordinateur tombe en panne, et pour les montrer au monde.
C'est aussi ton CV de développeur : les recruteurs vont souvent regarder ce que tu as publié.
Ton projet, sur GitHub, s'appelle un dépôt. En anglais, un repository.
[énergique] Ta mission : crée un compte gratuit sur github point com. Ensuite, clique sur New, appelle ton dépôt « mon-site », laisse-le public, et crée-le. Ne coche rien d'autre pour l'instant.
GitHub va t'afficher des commandes : garde cette page ouverte.
[souriant] Prochain épisode : on envoie ton premier code sur GitHub. Ton pseudo, c'est quoi ?
