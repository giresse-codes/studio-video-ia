[direct] Ton site a un squelette. Aujourd'hui, on l'habille.
Le HTML dit ce qu'il y a sur la page. Le CSS dit à quoi ça ressemble : couleurs, tailles, espaces.
Crée un fichier style point css. Puis, dans le head de tes pages, relie-le avec une balise link. Elle est à l'écran.
Une règle CSS a trois parties. Le sélecteur : ce que tu veux habiller, par exemple h un. La propriété : ce que tu changes, par exemple color. Et la valeur : la nouvelle couleur.
[amusé] Sélecteur, propriété, valeur. Qui, quoi, comment. Comme une consigne de styliste : le titre, la couleur, en rouge tomate.
[énergique] Ta mission : dans style point css, écris h un, accolade, color deux-points tomato point-virgule, accolade fermante. Actualise ta page : ton titre change de couleur. Puis add, commit, push.
