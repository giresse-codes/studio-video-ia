# studio-video-ia

Studio de vidéos animées verticales (Remotion + TypeScript) pour deux chaînes françaises : **DevsTeach** (programmation et IA expliquées par des objets du quotidien) et **Astuces** (problèmes courants et solutions malignes).

## Structure

- `channels/devsteach/scripts/` : scripts des vidéos DevsTeach
- `channels/astuces/scripts/` : scripts des vidéos Astuces
- `public/audio/` : voix off générées hors dépôt
- `src/` : code Remotion des compositions
- `out/` : rendus (non versionnés)
